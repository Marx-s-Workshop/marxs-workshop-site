Privacy Policy

Last Updated: May 11, 2026

Marx's Workshop ("we", "us", or "our") operates internal management software to streamline operations for our verified Etsy storefront. This policy outlines our practices regarding data collection, usage, and sharing as required by third-party API providers (including Etsy, Inc.).

1. Information We Collect via API

Our application accesses transactional and operational data purely related to our own seller account via secure API integrations. This includes:

  • Inventory & Listings data managed directly by our workshop.
  • Shop information and configurations.
  • Order and transaction summaries strictly for self-fulfilling shipping logistics.

2. How Data Is Used

Data retrieved through authorized API channels is used EXCLUSIVELY for internal inventory reconciliation, performance tracking, and automating shipping fulfillment queues. We do NOT aggregate, rent, sell, or externally share any data retrieved via API to third parties.

3. Data Storage & Security

All operational data is stored securely within localized protected environments utilizing standard encryption practices. Access is restricted solely to the licensed owner of the connected Etsy storefront.

4. Data Retention & Deletion

We retain data only as long as necessary for fulfillment and accounting records. Users may request data audit or complete removal by contacting our engineering desk directly via standard Etsy messaging channels.

5. Policy Compliance

Our application operates in absolute conformance with the Etsy API Terms of Use. We respect all User data safeguards and do not operate under public SaaS distributions.
